# AI Disclosure

Parts of this project were written with AI coding assistants (Claude, ChatGPT)

## Which work was AI-assisted
- Schema review against the challenge booklet to verify our work.
- Tests used to check rules, verify complete delivery day, and E2E tests of each role
- Some documentation, including the judge-walkthrough HTML file.
- Many of the coding work was handed to an AI tool once the initial designs, schema and architecture was agreed on by the team.

## Which work wasn't AI-assisted
- Design decisions, including the decision to change the Dispatcher UI from the initial Designathon submission.
- Architectural decisions and tech stack.
- Initial database schema. This was created manually and then iterated on using an AI tool using the constraints from the challenge booklet.
- PRs, and code reviews. Every change was merged after making a pull-request, reviewed by one of the teammates, and approved.Standard SDLC practices were used, including feature branches, default branch protection.
- Deployment and docker setup.
- Some manual coding work was also done by some team-members due to subpar AI code generation.
